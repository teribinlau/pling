# 叮一下 · 微信 / QQ / 群机器人申请指南

给部署叮一下的机构（学校、公司）的 IT 负责人看。这些账号**要用机构自己的主体去申请**：平台把登录和消息都记在申请主体名下，我们不能代办。

> 各平台的规则、费用和审核时间经常调整。下面写的是 2026 年 10 月查到的情况，申请时请以平台页面为准。文末列了参考链接。

## 先看：要不要全部申请？

| 功能 | 需要申请 | 没申请时 |
|---|---|---|
| 邮箱验证码登录 | 一个能发信的邮箱（SMTP），见《部署指南》 | **至少要有它，或者下面任一种**，不然第一个管理员登不进来 |
| 电脑上「微信扫码登录」 | 微信开放平台：开发者资质认证 + 网站应用 | 不显示这个按钮 |
| 微信里「一键登录」 | 已认证的**服务号** | 不显示 |
| 提醒发到微信 | 同一个已认证的服务号 + 模板消息 | 只有应用内提醒和群机器人 |
| QQ 登录 | QQ 互联：开发者认证 + 网站应用 | 不显示 |
| 提醒发到企业微信 / 钉钉 / 飞书群 | 群里加一个自定义机器人，不用找平台申请 | 不发到群 |

**共同前提：域名已完成 ICP 备案，网站已经能用 https 打开。** 微信、QQ 审核时都会填备案号或检查回调域名的备案。

建议的顺序：先用邮箱登录把系统跑起来 → 群机器人（几分钟就好）→ 服务号（推送 + 微信内登录，用得最多）→ 开放平台网站应用（电脑扫码）→ QQ 互联。

下文用 `pling.example.cn` 代表你们的域名。

---

## 1. 微信服务号（微信里一键登录 + 提醒消息）

### 1.1 注册和认证

1. 在 [微信公众平台](https://mp.weixin.qq.com) 用机构主体注册**服务号**（订阅号不行）。
2. 完成**微信认证**（要交审核服务费，以页面为准）。网页授权和模板消息都**只对已认证的服务号开放**（政府、事业单位、媒体类型的已认证公众号也可以）。
3. 在「服务类目」里选一个和用途相符的类目，比如教育相关，或者「商务服务 > 软件 / 建站 / 技术开发」。模板消息是按类目给模板的。

### 1.2 开发配置

2025 年起，服务号的开发配置挪到了 [微信开发者平台](https://developers.weixin.qq.com/platform)。登录后进入 **服务号 → 基础信息**：

| 配置 | 位置 | 填什么 |
|---|---|---|
| AppID / AppSecret | 开发密钥 | 抄下来，填进 `deploy/.env` 的 `WECHAT_MP_APPID` / `WECHAT_MP_SECRET` |
| API IP 白名单 | 开发密钥 | 服务器的**公网出口 IP**（在服务器上运行 `curl -s ifconfig.me` 可以查到）。不加的话发消息会报 40164 |
| 消息推送（服务器配置） | 域名与消息推送配置 | URL：`https://pling.example.cn/api/functions/v1/wechat-mp`<br>Token：自己编一个 3–32 位字母数字，同时填进 `.env` 的 `WECHAT_MP_TOKEN`<br>EncodingAESKey：点随机生成即可<br>消息加解密方式：**明文模式**或**兼容模式**（叮一下不支持安全模式） |
| 网页授权域名 | 「域名与消息推送配置」或公众平台的「功能设置」（以页面为准） | `pling.example.cn`（只填域名，不带 https://） |

**第一步要先把服务器装好**：填消息推送 URL 时微信会立刻访问它验签。所以先把 `WECHAT_MP_TOKEN` 写进 `.env`，运行 `docker compose up -d`，再到微信后台点「提交」。

**网页授权域名的校验文件**：设置时微信会让你下载一个 `MP_verify_xxxx.txt`。把它放到服务器的 `data/web-extra/` 目录，然后运行 `docker compose restart web`。确认 `https://pling.example.cn/MP_verify_xxxx.txt` 能打开，再回微信后台确认。

> ⚠️ 启用「消息推送」以后，公众平台后台里设置的**自动回复和自定义菜单会失效**（消息都转给了我们的服务器）。如果服务号原来就在用菜单，需要通过接口重新设置菜单，或者用一个新的服务号专门给叮一下。用户给服务号发消息时，叮一下会回一条带应用链接的说明。

### 1.3 模板消息（提醒推送）

1. 在公众平台的「模板消息」里，从模板库**选用**一个和提醒相关的模板。按你们的类目找，比如「待办事项提醒」「日程提醒」「作业提醒」「任务到期提醒」。
2. 打开模板详情，看它的字段。例如：
   ```
   事项名称：{{thing1.DATA}}
   截止时间：{{time2.DATA}}
   当前状态：{{phrase3.DATA}}
   ```
3. 把模板 ID 填进 `.env` 的 `WECHAT_MP_TEMPLATE_ID`。再按模板详情里的字段名，写出提醒内容和字段的对应关系，填进 `WECHAT_MP_TEMPLATE_FIELDS`：
   ```
   WECHAT_MP_TEMPLATE_FIELDS=title=thing1,time=time2,stage=phrase3
   ```
   可以用的内容：

   | 内容 | 是什么 | 适合的字段类型 |
   |---|---|---|
   | `title` | 提醒标题 | thing（20 字以内，超出截断） |
   | `time` | 这一次的到期时间（`2026年10月04日 08:30`） | time |
   | `stage` | 即将到期 / 已到期 / 已逾期 | phrase（5 字以内） |
   | `team` | 指派的班级 / 部门 | thing |
   | `creator` | 创建人 | thing 或 name |
   | `note` | 备注第一行 | thing |

   字段类型要对上，不然微信会拒收（错误码 47003）。没有合适模板时，`title` + `time` 两个字段也够用。
4. 改完 `.env` 运行 `docker compose up -d`。然后用管理员账号登录叮一下，在「设置 → 通知」里扫码绑定服务号，点「给我发一条测试消息」。

模板消息只能发**服务通知**，不能发营销内容；每天的发送量有上限，普通机构用不到。成员要**关注服务号**才收得到，取消关注后叮一下会把他标成「已取消关注」。

### 1.4 填好的 .env 片段

```
WECHAT_MP_APPID=wx1234567890abcdef
WECHAT_MP_SECRET=0123456789abcdef0123456789abcdef
WECHAT_MP_TOKEN=plingToken2026
WECHAT_MP_TEMPLATE_ID=AbCdEf...（模板 ID）
WECHAT_MP_TEMPLATE_FIELDS=title=thing1,time=time2,stage=phrase3
```

## 2. 微信开放平台（电脑上扫码登录）

1. 在 [微信开放平台](https://open.weixin.qq.com) 用机构主体注册开发者账号，在「账号中心」完成**开发者资质认证**（要交审核服务费，以页面为准；个人主体通常办不了网站应用的微信登录）。
2. 「管理中心 → 网站应用 → 创建网站应用」，需要准备：
   - 网站名称、简介、图标；
   - 网站地址 `https://pling.example.cn`；
   - 《网站信息登记表》：下载后填写**网站备案号**、主办单位、负责人信息，**盖公章**后扫描上传。
3. 填**授权回调域**：`pling.example.cn`（只填域名）。叮一下的回调地址是 `https://pling.example.cn/api/functions/v1/auth-callback`，在这个域名下就行。
4. 提交审核，通过后拿到 AppID / AppSecret，填进 `.env`：
   ```
   WECHAT_OPEN_APPID=wx...
   WECHAT_OPEN_SECRET=...
   ```

### 打通「同一个人」（UnionID）

如果服务号和网站应用都要用，在开放平台「管理中心 → 公众号 → 绑定公众号」里把服务号绑过来。绑定以后，同一个人用电脑扫码和在微信里登录，会被认成同一个账号；不绑的话会变成两个账号。**最好在大家开始用之前就绑好。**

## 3. QQ 互联（QQ 登录）

1. 在 [QQ 互联](https://connect.qq.com) 注册并完成**开发者认证**（个人或企业都可以）。
2. 「应用管理 → 创建应用 → 网站应用」，填网站名称、网站地址 `https://pling.example.cn`、图标等。
   - 如果要求在首页加 `<meta>` 标签验证网站：把那一行填进 `.env` 的 `PLING_HEAD_HTML`，例如：
     ```
     PLING_HEAD_HTML='<meta property="qc:admins" content="1234567890" />'
     ```
     运行 `docker compose up -d` 后，再回 QQ 互联点验证。
3. **网站回调域**：`https://pling.example.cn/api/functions/v1/auth-callback`。这个域名必须已在工信部备案，否则保存不了。
4. 审核一般要几个工作日。通过后把 APP ID / APP Key 填进 `.env`：
   ```
   QQ_APPID=101234567
   QQ_APPKEY=...
   ```
5. （可选）如果同一机构还有别的 QQ 应用要认同一个人，向 QQ 互联申请 UnionID 打通。

## 4. 群机器人（企业微信 / 钉钉 / 飞书）

不用找平台审核，**群主或管理员在群设置里就能加**。加好以后，把机器人地址填进叮一下的「设置 → 群机器人」。在那里给每个班级 / 部门配一个，也可以给「全体」配一个；点「测试」能马上看到效果。

| | 企业微信 | 钉钉 | 飞书 |
|---|---|---|---|
| 怎么加 | 群聊 → 右上角 → 消息推送（群机器人）→ 添加 | 群设置 → 机器人 → 添加机器人 → 自定义 | 群设置 → 群机器人 → 添加机器人 → 自定义机器人 |
| 地址 | `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=…` | `https://oapi.dingtalk.com/robot/send?access_token=…` | `https://open.feishu.cn/open-apis/bot/v2/hook/…` |
| 安全设置 | 无（地址本身就是密钥，别外传） | **必须选一种**：推荐「加签」，把密钥（`SEC` 开头）填进叮一下；或者「自定义关键词」填 `叮一下` | 推荐「签名校验」，把密钥填进叮一下；或者「自定义关键词」填 `叮一下` |
| @ 人 | 按手机号 @（成员在叮一下里填了手机号才行） | 按手机号 @ | 不 @（飞书自定义机器人只能按飞书 ID @） |
| 频率 | 每个机器人每分钟 20 条 | 每个机器人每分钟 20 条，超了会被限流 10 分钟 | 有频率限制 |

叮一下每条消息都以「【叮一下】」开头，所以关键词填「叮一下」就能通过。每个机器人每分钟最多发 15 条，多的顺延到下一分钟，不会撞上平台的限流。

**机器人地址等于往群里发消息的权限**，只有叮一下的管理员能看到和修改。

---

## 5. 都填好以后

```bash
cd /opt/pling/deploy
nano .env                 # 填上面拿到的 AppID、密钥等
docker compose up -d      # 应用配置（或者 scripts/install.sh，效果一样）
```

刷新登录页，就能看到新的登录按钮。如果按钮没出现，看《部署指南》的「常见问题」。
